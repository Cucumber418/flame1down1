# 游戏敏感词表

这是本项目采用的可维护关键词表，不是官方发布的统一“中国违禁词库”，也不能判断一句话在所有语境中是否违法。

按维护者在 2026-11-17 的选择，默认启用辱骂、色情、赌博诈骗、广告及政治敏感词。规则用于玩家新提交或修改的文字；命中后拒绝提交并提示修改，不替玩家改写，也不回显命中词。

## 误伤调整

不引入 NLP 停用词，不将源项目的“其他”“民生”“疫情”等混合词表整体设为禁词。已从所选源文件中排除单字，以及“网络、客服、免费使用、内衣”等普通/中性词；配置见 [exclusions.json](exclusions.json)，构建时实际排除的完整清单见 [excluded.json](excluded.json)。政治类别按维护者要求启用，其中包含人名与公共议题，会拦截正常讨论；这些条目只代表本项目的过滤配置。

## 范围与行为

- 检查注册账号名、做题家名字、精灵昵称、配队名、基地名、名片签名。
- 检查讨论区、BOSS 攻略、私信、基地留言、基地摸宠事件中的精灵名字、观战弹幕。
- 浏览器提前提示；服务器对 API/交易和存档上传再次检查，绕过网页仍不能提交。
- 精灵改名在修改昵称前校验；做题家改名在扣卡前校验。空昵称仍能恢复默认名。
- 仅检查存档中新增/修改的自定义文字。旧存档里未修改的文字不阻断正常进度同步，不追溯删除历史消息。
- 不扫描密码、游戏剧情、技能表、系统邮件、战斗数据等固定/非玩家输入内容。
- 匹配支持 NFKC 全半角统一、英文字母大小写、空格/标点/零宽字符分隔、代码中列出的常见繁体字转换。英文/数字词保留单词边界，避免把较长普通单词的片段当禁词；这不是完整繁简或谐音识别。
- 仅在本地执行关键词检查，不记录用户命中词日志。维护者可通过版本管理审核词表变化。

## 修改和构建

修改源文件、`custom.json` 或 `exclusions.json` 后，在仓库根目录执行：

```sh
python tools/build_content_words.py
node tests/content-filter.cjs
```

构建会重建各分类、`all.txt`、`excluded.json`、`manifest.json` 和浏览器/服务器共用的 `js/data/content-words.js`。运行时不联网更新词库。
