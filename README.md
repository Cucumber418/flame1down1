# 手绘精灵对战（试验版）

一款类宝可梦的精灵对战网页游戏，精灵全部来自手绘图鉴，战斗方式参考赛尔号。

## 怎么玩

把整个仓库下载到电脑（绿色 **Code** 按钮 → **Download ZIP**），解压后双击 `index.html`，用浏览器打开即可。不需要安装任何东西。

注意：`index.html` 必须和 `images` 文件夹放在同一个目录里，否则图片显示不出来。

## 文件说明

| 位置 | 内容 |
|---|---|
| `index.html` | 游戏的全部代码：页面、样式、战斗逻辑、精灵数据、剧情 |
| `images/sprites/` | 精灵立绘（最终形态） |
| `images/pre_sprites/` | 进化前形态的立绘（`_s1` 是第一阶段，`_s2` 是第二阶段） |
| `images/lineart/` | 手绘原画扫描 |
| `images/backgrounds/` | 剧情和探索场景的背景图 |

图片文件名就是精灵的 id，例如 `dragon.png`。想换某只精灵的图，直接用同名文件覆盖即可。

## 一起修改的约定

1. 动手改之前，在群里说一声"我在改"，改完提交了再说一声，避免两个人同时改 `index.html`。
2. 改之前先确认拿到的是仓库里最新的版本。
3. 提交时写清楚改了什么，例如"新增 15 只精灵"、"修复换精灵时血条不刷新"。

## 存档

游戏进度（账号、排位、队伍等）保存在浏览器本地，换电脑或换浏览器后不会同步。
