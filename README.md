# Flame1Down - 1（试验版）

一款类宝可梦的精灵对战网页游戏。精灵来自手绘图鉴，战斗方式参考赛尔号，带有账号、配队、图鉴和星际探索剧情。

## 怎么玩

把仓库下载到电脑（绿色 **Code** 按钮 → **Download ZIP**），解压后双击 `index.html`，用浏览器打开就能玩，不需要安装任何东西。

整个文件夹要保持原样：`index.html`、`css`、`js`、`images` 必须放在同一个目录里。

## 目录结构

```

css/style.css         全部样式
js/
  data/               游戏数据，平时加内容基本只改这里
    types.js          属性颜色、属性克制表
    moves.js          技能表
    creatures.js      精灵表（种族值、进化、特性、技能列表）
    story.js          星际探索剧本（全部对话）
    changelog.js      更新公告（航行日志里的「近期改动」）
    wild.js           各星球的野外精灵和区域（出现概率、捕捉率）
    assets.js         图片路径表
    ship-map.js       荆楚号平面图的区域坐标
  engine/             对战规则，和界面无关
    battle.js         能力值、伤害公式、状态、回合流程、道具
    ai.js             电脑怎么选技能、换精灵
    ranked.js         平衡排位、电脑强度、配招、公平阵容
  net/
    cloud.js          账号登录与云存档（用服务器打开时先登录，进度自动上传）
  ui/                 界面
    battle-ui.js      竞技对战页面：选精灵、对战画面、动画
    game.js           账号、背包、仓库、黄冈秘鉴、航行日志、星际探索、商城、茶室、任务、每日任务、改名卡
    social.js         社交：玩家 / 好友 / 我的名片，联网切磋，观战
    board.js          顶栏的「关于」和「讨论」（公开留言板）
    audio.js          背景音乐（界面 + 战斗）、顶栏「声音」设置
images/
  sprites/            精灵立绘（最终形态），文件名 = 精灵 id
  pre_sprites/        进化前形态，id_s1 是一阶，id_s2 是二阶
  lineart/            手绘原画扫描

  characters/         剧情角色立绘、表情差分、图标
```

`index.html` 最先加载 `js/net/cloud.js`，其他脚本写在它下面的 `CLOUD.boot([...])` 列表里，登录完成后按列表顺序加载。顺序是固定的：数据 → 引擎 → 界面。后面的文件会用到前面文件里定义的东西，所以不要调换顺序。新增 js 文件时，把路径按这个规则插进列表里合适的位置。

## 常见修改

### 改数值、改技能描述

直接在 `js/data/creatures.js` 或 `js/data/moves.js` 里找到对应的精灵或技能改数字。用编辑器的搜索功能（Mac 上 `Cmd + F`）搜精灵名或技能名最快。

### 新增一只精灵

1. 在 `js/data/creatures.js` 的 `SP` 列表里照着已有的格式加一项。`id` 用英文小写，例如 `fox`。
2. 技能如果是新的，在 `js/data/moves.js` 的 `M` 里加上。精灵的 `moves`、`hidden`、`def` 里写的技能名必须和 `M` 里的完全一致。
3. 把立绘放进 `images/sprites/`，文件名用 id，例如 `fox.png`。
4. 打开 `js/data/assets.js`，在 `SPRITES` 里加一行 `"fox": "images/sprites/fox.png",`。
5. 有进化前形态的话，图片放进 `images/pre_sprites/`，命名为 `fox_s1.png`、`fox_s2.png`，并在 `PRE_SPRITES` 里加对应的行。手绘原画同理，放 `lineart/`，登记在 `LINEART`。

只在账号系统里出现、不参加竞技对战的精灵，加在同一个文件里的 `EXTRA_SP`。

### 改剧情对话

剧本都在 `js/data/story.js`。每个地点是一个列表，一行是一句话，例如：

```js
{ s: 'v', on: [['p', 'l'], ['v', 'r']], t: '{name}！这边这边！' },
```

- `s`：说话人。`n` 是旁白，`p` 是玩家，其他代号见 `js/ui/game.js` 里的 `CAST`
- `t`：台词。`{name}` 会自动换成玩家的名字
- `on`：站在画面上的角色和位置（`l` 左，`r` 右）
- `bg`：切换背景，值是 `BG` 里的名字

新增一个剧情地点时，除了在 `story.js` 里加剧本，还要在 `js/ui/game.js` 的 `SITES` 里登记这个地点。

- `mons`：画面中间显示的精灵。`tw:精灵id` 是被瘴气污染的样子；`mon:精灵id:等级:标签` 是普通样子（例如 `mon:kaleo:15:？？？`）
- 精灵也能当说话人：`CAST` 里写 `spr: 精灵id`（`sprLv` 指定等级，决定显示哪个形态），例如卡罗 `kr`、卡莱 `kl`

### 主线章节

主线分成若干章节（`js/ui/game.js` 的 `CHAPTERS`）。一个章节的剧情全部读完，会额外发一份章节大奖（存档里记在 `chapters`，每个存档一次）；章节推出前就已经读完的，打开游戏时通过邮箱补发。还没写完的章节标 `wip: true`（未完待续），写完之前不算通关，写完后去掉它，已经读完的人会自动收到奖励。

| 章节 | 包含 | 章节大奖 |
|---|---|---|
| 序章 | 第一段～第四段（省实验中学 → 登上荆楚号） | 累积经验 5000 |
| 第一章 · 芙罗拉星（未完待续） | 第五段 降临芙罗拉、第六段 卡罗的不安、第七段 猎杀者…… | 茶室音乐「芙罗拉星」 |

**第六段读完后的主线任务「引出猎杀者」**：芙罗拉星丛林、草甸的野生精灵不会倒下，体力剩 1 点时逃走（战斗结果 `spared`，算击败，有经验），记作「假装击败」，攒满 5 只开放第七段（存档 `story.flora2.spare`，规则在 `game.js` 搜「引出猎杀者」，引擎在 `battle.js` 的 `faint()`）。

剧情道具（`game.js` 的 `KEY_ITEMS`）：精灵翻译器（第六段）、烟雾保护头盔（第七段），显示在储存箱的一般道具里，不能使用。道具图放在 `images/items/`，登记在 `assets.js` 的 `ITEM_IMG`（无人机只在剧情里出现）；剧本里写 `mons: 'item:图名:标签'` 就会在画面中间显示道具。

### 换图片

用同名文件直接覆盖 `images/` 里的旧图即可，代码不用改。如果新图的格式不同（比如 png 换成 webp），记得同步改 `js/data/assets.js` 里的文件名。

## 修改后怎么检查

1. 改完保存，在浏览器里刷新 `index.html`。
2. 如果页面空白或者点了没反应，按 `Cmd + Option + I` 打开开发者工具，看 **Console** 里的红色报错，一般会写出是哪个文件、第几行出了问题。最常见的原因是少了逗号或括号。

## 一起修改的约定

1. 动手改之前在群里说一声，改完提交了再说一声，尽量不要两个人同时改同一个文件。
2. 改之前先拉取仓库里的最新版本。
3. 提交时写清楚改了什么，例如"新增精灵：狐火"、"修复换精灵时血条不刷新"。

## 服务器（联网版）

游戏也部署在一台腾讯云轻量服务器上，用浏览器打开 `http://服务器IP` 就能玩，联网对战也走这台服务器。

```
server/
  server.js           服务器程序：发网页 + 在 /ws 上给联网对战传话
  accounts.js         账号与云存档（注册、登录、上传存档）
  social.js           社交：玩家列表、好友、名片、在线状态、切磋邀请与对战转发、观战转播
  board.js            讨论区（公开留言板），留言存在存档目录的 board.json
  admin.js            管理账号（列出账号、帮人重设密码）
  setup.sh            第一次安装用（装 Node.js、注册成开机自启的服务）
  update.sh           以后更新用
  backup.sh           备份所有存档（定时自动运行，也可手动）
  restore.sh          从备份恢复存档
  install-backup.sh   安装每 6 小时一次的自动备份（自动部署时会自动运行）
  node_modules/ws     WebSocket 库，直接放进仓库，服务器上不用再 npm install
```

**第一次安装**：在腾讯云控制台登录服务器的网页终端，粘贴运行：

```
sudo git clone --depth 1 https://github.com/Cucumber418/flame1down1 /opt/flame1down1 && sudo bash /opt/flame1down1/server/setup.sh
```

**自动部署（推荐）**：`.github/workflows/deploy.yml` 会在每次推送到 main 后，由 GitHub 把新版本上传到服务器并重启，不需要服务器去连 GitHub。一次性设置：在服务器上用 ubuntu 账号运行 `bash /opt/flame1down1/server/setup-deploy.sh`，把它打印的 `DEPLOY_HOST` 和 `DEPLOY_KEY` 填进仓库 Settings → Secrets and variables → Actions。部署记录在仓库的 Actions 页面里看。

**手动更新**：在服务器终端运行 `sudo bash /opt/flame1down1/server/update.sh`（国内连 GitHub 不稳定时可能卡住）。

80 端口被占用时（比如镜像自带了 caddy / nginx），可以换端口安装：`sudo bash /opt/flame1down1/server/setup.sh 8080`，然后在腾讯云防火墙里放行这个端口，用 `http://服务器IP:8080` 打开。

**账号与存档**：用服务器打开游戏时要先登录。存档保存在服务器的 `/opt/flame1down-data`（在仓库外面，更新代码不会影响它，网页也读不到）。密码只保存加盐哈希。
- 列出所有账号：`sudo node /opt/flame1down1/server/admin.js list`
- 有人忘记密码：`sudo node /opt/flame1down1/server/admin.js reset 账号名 新密码`
- 讨论区有不合适的留言：`sudo node /opt/flame1down1/server/admin.js board` 看最近 30 条（带编号），`sudo node /opt/flame1down1/server/admin.js board-del 编号` 删掉
- 建议在腾讯云控制台给服务器定期做快照，万一服务器出问题可以恢复存档。

**检查是否在运行**：浏览器打开 `http://服务器IP/ping`，显示 `ok` 就正常；`http://服务器IP/status` 能看到在线人数和房间数。

## 王者星数

平衡排位打到王者后不再晋级，胜一局 +1 星、负一局 −1 星（0 星再输掉回宗师）。存档里 `hs-rank-v1` 的 `kingBest` 记录王者达到过的最高星数，社交的玩家列表和名片显示「王者 N 星」。

王者段位里电脑随星数变强（`js/engine/ranked.js` 的 `rankAI(r, stars)`，每星一档，最多算到 `KING_CAP` = 30 星）：能力值倍率从 ×1.15 涨到 ×1.45，配招比较的方案从 12 套涨到 42 套，估分更准、更常换人躲克制，对手阵容的隐藏强度比你高一点（30 星时阵容本身约 57% 胜率）。

## 社交与联网切磋

主菜单「社交」（在星际探索左边），需要用服务器网址打开并登录：

- **玩家**：所有注册过的账号，显示在线 / 对战中 / 离线。点一位玩家看他的名片。
- **好友**：点「加好友」把别人加进来（单向，像关注）。对方也加了你时会显示「互相关注」。
- **我的名片**：选最多 5 只展示精灵，写最多 200 字的个人宣言。名片存在游戏存档里，同步到服务器后别人就能看到。
- **我的茶室**：「我的名片」旁边的按钮，直接去自己的茶室。
- **切磋**：对在线的玩家点「切磋」，选规模（1v1 / 3v3 / 5v5）和规则。对方会立刻弹窗，30 秒内接受或拒绝。每回合 90 秒，超时自动出招。切磋不影响经验和段位。
  - **常规模式**：双方各派出出战配队的前 N 只精灵，按背包里的练度（等级、性格、学习力、技能、纹章）对战（服务器从存档里取，不能作假）。
  - **平衡模式**：所有精灵统一 LV60，技能库全部开放（自己选 4 个，默认用竞技对战里记住的配招，选好的也会记回去），性格无修正，没有学习力和纹章。接受后先进入选人阶段，服务器当裁判：
    - **普通盲选**（1v1、3v3、5v5 都有）：双方各从自己拥有的精灵种类里选 N 只并配技能，看不到对方选了什么。
    - **竞技征召**（只有 5v5）：双方各带 8~10 种精灵（要拥有至少 8 种）→ 各禁用对方 3 种 → 从自己剩下的里选 5 只并配技能。带精灵 90 秒、禁用 60 秒、选人 150 秒，超时由服务器代选。
    - 选人阶段可以退出，对方会收到提示，这场切磋取消。
- 联网对战由发起方的浏览器结算，结果和战况发给对方播放，所以两边看到的过程一定一样。对方掉线时直接判你获胜。
- **观战**：好友正在对战时（任何对战：野外、剧情、首领、茶室、竞技对战、切磋、大乱斗），玩家列表里显示「对战中 · 对战类型」和「👁 观战」按钮，点开就是实时的对战画面（信息牌、立绘和动画、战斗记录）。只能看自己加了好友的人。对战的玩家在战斗记录标题旁能看到小眼睛「👁 N」，点开是观众名单；观众在观战窗口右上角也有同样的小眼睛，能看到还有谁在看（服务器在观众进出时发 `cast-viewers` 给对战者、`watch` op=viewers 给每个观众）。
  - **全服观战邀请**：两名玩家对战（切磋、大乱斗）时，任一方可以点对战画面里的「邀请全服观战」，所有在线船员右下角会收到邀请，之后不是好友的人也能看这场。每场每分钟最多邀请一次。
  - 原理：对战的浏览器每 0.25 秒把画面（战况快照、新的战斗记录、出招 / 受伤动画提示）发给服务器，服务器转给观众（`server/social.js` 里的 cast / watch 消息）。平衡排位里对手还没派出的精灵，观众也看不到。
- **拜访茶室**：玩家列表和名片里的「茶室」按钮，可以看对方茶室里正在训练的精灵，并用自己的出战配队挑战它们（电脑操控）。每天前 5 场茶室对战各奖励 1000 累积经验（进经验背包），赢输都算，认输不算，0 点刷新。对方要读完「陆羽茶室」支线才有茶室。

改名卡：荆门 · 物资仓储的商城里 1000 能量一张，兑换后点右上角的名字，在菜单里使用。

## 精灵大乱斗（竞技对战的第三种模式）

需要联网，并且有其他玩家在线时才能开始。

**开放条件**：持有 3 只精灵后，星际探索 · 荆楚号 · 孝感大厅出现支线「精灵大乱斗」，Dr.黄 介绍完就开放这个模式；之后打完一场大乱斗（自己认输不算）支线完成。没开放的玩家不会收到匹配邀请，也不算在「可匹配」人数里。

1. 从出战配队里选 3 只（配队至少 3 只），点「开始匹配」。
2. 其他在线、没在对战的玩家右下角会弹出小提示，点「接受」后也选自己的 3 只。谁先确认谁成为对手，60 秒没人接受自动取消。
3. 双方的 6 只精灵由服务器按存档核对，统一为 LV60、学会全部隐藏技能、配招为技能表的最后 4 个、没有学习力、性格随机，打乱后每人随机分 3 只（可能分到对方的）。
4. 对战流程和切磋一样。胜者 2000、败者 1000 累积经验，平局各 1000；自己认输或自己掉线没有奖励。每天大乱斗经验上限 20000。

开打时会播放抽选动画（6 只翻面洗牌后重新发给两边，`js/ui/social.js` 的 `brawlShow`），只是效果，对战已经在后面开始了。

规则常量在 `js/ui/game.js` 搜「精灵大乱斗」；匹配和发牌在 `server/social.js`。

## 异色精灵

野外精灵表（`js/data/wild.js`）里给某种精灵写 `shiny: 0.03`，遇到的这只就有 3% 概率是异色。异色的立绘放在 `images/shiny/`，在 `js/data/assets.js` 的 `SHINY_SPRITES` 里登记（键名和 `PRE_SPRITES` 一样，最终形态用精灵 id）。抓到后精灵身上记 `shiny: true`，卡片、资料、名片、对战里都标「异色」；某个形态没有异色立绘时显示普通立绘。目前：锰怪（雷公一阶）3%；锰怪、三合一锰怪是红色异色，最终形态雷公是橙色异色，三个形态都有异色立绘。

## 茶室商店（陆羽茶室大厅）

- **7日自律训练装置**：1500 能量。在「我的房间」给展示中的精灵装上，它每训练满 1 天就自动结算经验（24 小时的量）并重新计时，一共 7 天；离线也算，下次打开游戏时补上。中途收回精灵，剩下的天数作废（收回时要点两次确认）。
- **茶室精灵容量 +1**：依次 2000 / 5000 / 10000 / 20000 能量，最多买 4 次，茶室最多同时展示 7 只（存档里 `home.cap`）。
- 规则在 `js/ui/game.js` 搜「茶室商店」。

**茶室音乐**：「我的房间」里可以选茶室音乐，自己和来拜访的船员在茶室里都会听到（存档里 `home.bgm`）。「大厅」（默认，就是一般界面的音乐）和「地球」一开始就有；「芙罗拉星」是主线第一章「芙罗拉星」的章节大奖（2026-10-12 上午曾短暂作为普通荒芜的首次奖励，那时已经拿到的船员保留，判断依据是存档里的 `mailSeen['barren-bgm']`）。曲目表在 `js/ui/game.js` 的 `HOME_BGM`，服务器在 `server/social.js` 的 `homeOf()` 里再核对一次。

## 朋友回家（陆羽茶室）

Threego、Dr.黄、Bttp 每天会在一个随机时段回到自己在陆羽茶室的房间（北京时间 9:00–24:00 之间，每人每天一次，每次 3 小时）。时段和他们带的精灵都用当天日期算出来，所有玩家看到的一样。

- 在家时，大厅里对应的房间会标「● 主人在家」，进房间点人物或「对话」按钮，聊一句后进入对战。
- 每人带 3 只精灵，等级是你出战配队平均等级的 −5 / ±0 / +5。Threego 首发固定叶子喵，Dr.黄 必带至高之盾，Bttp 第三只固定骨刃，其余从竞技对战的精灵里随机（不含荒芜、豪瑞希德）。游戏里只提示「实力与你相当」。Dr.黄 的房间里平时展示一只 LV10 董之马。
- 电脑的出招水平按白银段位。
- 胜利奖励 3000 累积经验，每个 NPC 每天最多一次。
- 规则都在 `js/ui/game.js` 搜「朋友回家」，时长、时间范围、奖励数额都是开头的几个常量。

## 登录奖励、每日任务、平衡排位经验

都写在 `js/ui/game.js` 里，数额是各段开头的常量。

- **离线经验**（搜「登录奖励」）：距离上次在线超过 20 分钟再打开游戏（或电脑睡眠后回来），邮箱里会收到离线经验：离线 1 分钟 = 6 点累积经验，最多算 3 天（25,920 点）。游戏开着时每 2 分钟在存档里记一次在线时间（`lastActive`）。
- **每日登录**：每天（北京时间）一封 3000 累积经验的邮件；没登录的日子下次登录时一起补发，从创建账号那天算起（存档 `loginDay`）。
- **每日任务**（搜「每日任务」）：每天 7 个，必定有 3 个竞技对战任务；开放精灵大乱斗后 70% 的日子会有 1 个大乱斗任务（完成 1 场 / 获胜 1 场），其余从探索类里抽。2026-10-12 起奖励翻倍（`DAILY` 里写的就是翻倍后的数）；当天已经按旧标准领过的，差额通过邮箱补发。之前的日子没有逐日记录，补不了。
- **平衡排位经验**：竞技对战的「实战」改名为「平衡排位」。每天（北京时间）前 10 局平衡排位各奖励 600 累积经验，胜负都算，认输不算（存档 `rankExp`）。

## 首领、每周挑战、道具

首领写在 `js/ui/game.js` 的 `BOSSES` 里，每个首领分几档难度（`lv` 数组，按顺序解锁），首领页上方切换难度。
特殊能力写在 `boss` 里，规则在 `js/engine/battle.js` 的 `BOSS_FX`：

| 写法 | 效果 |
|---|---|
| `only: ['水','火','草']` | 只有这些属性的技能能命中它 |
| `noStatus` | 免疫异常状态 |
| `ne` | 【来东北试试】普通拳不降命中，还解除自身能力下降 |
| `dr: 0.15` | 【星球聚能】受到伤害减少 15% |
| `mia` | 【瘴气领域】每回合结束给对手在场精灵加 1 层瘴气 |
| `puppet` | 【瘴毒傀儡】每回合 30% 几率下场，召唤 LV50 傀儡（玛西露姆 / 六尾风王 / 卡莱奥丹之一，10 层瘴气，只用攻击技能）；冷却 15 回合，体力低于 1000 后 7 回合；傀儡倒下后首领回场 |
| `pp: 99` | 首领技能 PP（长时间战斗不会用光） |

所有首领战 60 回合内没击败首领算失败。

- **泰戈尔**（襄阳 · 古城防卫部）：简单 LV25 / 500 体力 → 首次击败送 LV10 小胖虎，并自动播放小剧情「来东北试试」（泰戈尔介绍普通难度）。普通 LV40 / 1500（【东北的纷争】物攻永久 +30%，2026-10-12 起不再免疫异常状态）→ 首次击败送「普通拳纹章」和 20000 累积经验。困难 LV60 / 5000（击败普通后开放；拥有普通难度的全部能力，不再免疫异常状态；隐藏特效【东北的往事】：第一次被击败时不屈复活为 LV60 / 3000 的「热血·泰戈尔」，播放一小段剧情，东北的纷争变为【永续的纷争】物攻 +60%、受伤 +20%，新增【往日重现】受击 50% 让对方烧伤 / 冻伤 / 中毒 1~3 回合，场地【沈阳大街】双方禁用变化技能。这个特效在玩家第一次触发之前不在首领页和状态栏显示，触发过记在存档 `seenFx.past`；代码在 `battle.js` 的 `reviveTiger`）→ 首次击败送称号「原力掌控者」、泰戈尔性格药剂 ×3、50000 累积经验。普通和困难都免疫异常状态、带【来东北试试】。

## 首领攻略板

每个首领的每个难度页面下方（每周挑战没有）。服务器在 `server/bossboard.js`，留言存在存档目录的 `bossboard.json`。

- **攻略 / 留言**：只有通过了这一档的人能发，每人每档一条（再发就是修改），最多 500 字，带 1~5 星评分；页面显示平均分。
- **赞 / 踩 / 欢乐**：赞和踩二选一，欢乐单独算，不能给自己点，再点一次取消。攻略按（赞 − 踩）排序。
- 有不合适的攻略：`sudo node /opt/flame1down1/server/admin.js boss` 看全部（带编号），`... admin.js boss-del 编号` 删掉。

## 野外的三主宠和米饭火鸡

`js/data/wild.js`：叶粒种子（芙罗拉星丛林 / 草甸，LV5）、水臂乌贼（坎布尔星，LV10）、方头蘑菇（庞贝星，LV12）各 0.25% 作为稀有精灵出现；米饭火鸡在庞贝星 0.5%（LV12）。野外改成场景遇敌后，卡莱、塞米、亚当这类稀有精灵也降到 0.5%（权重可以写小数，降下来的部分加给同区域最常见的精灵）。三主宠不算支线「稀有精灵」要找的稀有精灵（`rareOwned()` 排除了 `STARTERS`）。

## 新精灵和平衡排位

平衡排位（以及竞技对战的沙盒、图鉴）只用 `js/data/creatures.js` 里 `ARENA_ROSTER` 列出的 24 只。之后新加的精灵照常写进 `SP`，不在名单里就会自动转到 `EXTRA_SP`：只出现在星际探索、精灵背包 / 仓库和黄冈秘鉴里。`ranked.js` 算阵容时的属性覆盖也只算名单里有的属性，所以新属性（比如飞行）不会改变平衡排位的阵容。

- **冲锋火鸡**（`turkey`，火 / 飞行，2026-10-12）：米饭火鸡 → 饭香火鸡（LV25）→ 冲锋火鸡（LV50）。立绘待补，暂用问号占位图（`images/sprites/turkey.svg`、`pre_sprites/turkey_s1/s2.svg`）；在庞贝星作为稀有精灵出现（5%）。
  - 吃米饭（`custom: 'rice'`）、米饭香（`rice3`）、特性「饭香」（每回合结束 20%）都走 `battle.js` 的 `eatRice()`：随机回复 1/5 体力 / 物攻 +1 / 速度 +1，吃了几口记在 `m.perm.rice`。
  - 飞空连击 / 非凡连击：`hits: [6, 10]`、`fixedHit: 5`（每次命中附带的固定伤害按命中次数合起来结算一次）；非凡连击（`riceHits`）连击数再加吃过的米饭口数，最多 15 次。
  - 火鸡冲锋：`clearTgtUp` + `clearTgtChance: 0.4`。
- **飞行系**（`types.js`）：克制草，打电、机械减半；被电、冰克制（暂定，参考赛尔号）。

## 等级成就称号

`game.js` 的 `TITLES` 后面循环生成：有 1 只精灵达到 25 / 50 / 75 / 100 级得「单科达人 / 高手 / 狂人 / 神人」，有 5 只达到同样等级得「全科达人 / 高手 / 狂人 / 神人」。精灵升级时（`gainExp`）和每次打开游戏时都会检查。

经验曲线在 `game.js` 的 `expK()` / `expTab()`；存档 `expV` 是曲线版本号，改曲线时把版本号加 1，读档时会按「等级不变、本级进度比例不变」换算旧经验。

## 存档冲突误报（2026-10-12 修）

关页面时 `visibilitychange` 和 `pagehide` 连着触发：云存档先用 keepalive 把进度传上去，但页面关了收不到回复，本机的版本号没更新，下次打开就会弹「存档冲突」。现在 `cloud.js` 读档时如果服务器上的内容和本机一模一样就不算冲突（`sameData`），`game.js` 的 `markOnline()` 5 秒内也不会重复改存档。

## 表情

12 个表情图在 `images/emotes/`（从 `images/characters/` 里 Threego、Dr.黄、Bttp 的立绘差分裁出头部，256×256 透明 webp），清单是 `js/data/assets.js` 的 `EMOTES`（`emoteOf(id)` 查一个，`emoteMsg(text)` 判断一条私信是不是表情）。

- 联网对战：操作栏「😀 表情」（`#btn-emote`，只在切磋 / 大乱斗时显示）。点了先在自己的精灵（`#mon0`）头顶冒气泡，再通过对战消息 `{ k:'emote', e:id }` 发给对手，对手在 `#mon1` 头顶显示；同时用观战流 `{ a:'emote' }` 发给观战的人。每 3 秒最多一个。代码在 `js/ui/battle-ui.js` 搜 `showEmote`。

## 存档备份

服务器上的账号和存档（`/opt/flame1down-data`）会自动备份到 `/opt/flame1down-backups`：

- **每 6 小时一次**（0、6、12、18 点左右，系统定时任务 `flame1down-backup.timer`；服务器关机错过的那次，开机后会补上）
- **每次自动部署前一次**（文件名带 `deploy`）
- 每份是一个 `saves-日期-时间-标记.tar.gz`，**保留 30 天**，更早的自动删掉

这些都由自动部署装好，不用手动设置。打开 `http://服务器IP:8080/status` 能看到 `backups`：一共有几份备份、最新一份的文件名。在服务器上可以用：

```
sudo bash /opt/flame1down1/server/backup.sh manual      # 立刻手动备份一次
sudo bash /opt/flame1down1/server/restore.sh            # 列出所有备份
sudo bash /opt/flame1down1/server/restore.sh latest     # 恢复到最近一份
sudo bash /opt/flame1down1/server/restore.sh 文件名      # 恢复到指定的那份
```

恢复前会先把当前存档再备份一次（标记 `before-restore`），原来的存档目录也会改名留着，恢复错了可以再换回来。恢复会让在线的玩家断线几秒。

注意：备份和存档在同一台服务器上，能防误删、改坏存档，防不了整台服务器出问题。需要的话可以在腾讯云控制台给服务器做快照。

## 存档

- **用服务器打开（`http://服务器IP...`）**：要先登录账号。账号、精灵、段位等进度会自动保存到服务器，换电脑、换手机登录同一个账号就能接着玩。页面右上角的「☁ 账号名」显示保存状态，点开可以修改密码、退出登录。登录时勾选「自动登录」（默认勾上），60 天内打开网页不用再输密码；不勾的话关掉浏览器就要重新登录。
- **双击 `index.html` 本地打开**：不用登录，进度只保存在这台电脑的浏览器里，换电脑或换浏览器不会同步。

注意：浏览器按「网址」分开保存存档。双击 `index.html` 打开的本地版和 `http://服务器IP` 打开的联网版是两份独立的存档，互相看不到。
